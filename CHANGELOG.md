# Changelog

Notable changes to jilid, newest first.

## 0.2.0 - 2026-10-06

### Breaking changes

See [Migrating](https://github.com/shuretokki/jilid/blob/v0.2.0/README.md#migrating-from-01) for how to update a document.

- Title-only frontmatter and one appendix per call
- Digital margin and plain lecturer names by default
- Outline indent option, sub-chapter rows under chapter title by default
- Rename outline options to toc-indent and align-titles

### Features

- Institution line order and render hook on cover
- Align outline titles in a number column
- Monospace web links with url text style
- Label option on frontmatter for page references
- Toc-indent lengths line up chapter titles
- Guided template with skripsi outline and flowchart example

### Fixes

- Keep chapter numbers when frontmatter has = heading
- Allow outline and bibliography inside frontmatter and appendix
- Point 0.1 frontmatter and appendices calls to migration
- Keep toc out of shared outline number column
